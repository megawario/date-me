# Contributor and agent instructions

- Keep the project framework-free and deployable as plain static files.
- Keep `index.html` at the repository root for GitHub Pages compatibility.
- Separate content, presentation, and behavior across HTML, CSS, and JavaScript.
- Preserve semantic HTML, keyboard accessibility, visible focus states, descriptive image alternatives, and reduced-motion support.
- Use relative paths for internal links and assets.
- Do not add package dependencies, build tooling, backend services, authentication, APIs, persistence, or dating functionality during this foundation phase.
- Keep documentation concise and update `README.md` or `docs/plan.md` when the static-site scope changes.
